# Gamepad Mouse — Website

Marketing website for Gamepad Mouse, built with Astro and Tailwind CSS.

## Prerequisites

- Node.js 18+ (recommended: 20+)

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321) in your browser.

## Build

```bash
npm run build
```

Output is in `dist/`.
